# QA absorbs Demo and E2E; Done means pushed

Simplify the ADLC flow to Discovery → Architect → Approval → Developer → QA → Done. QA becomes the single verification stage: code and security review, an agent-driven browser run of the feature to find UI defects, and committed end-to-end tests for the flow, ending with the developer's recorded acceptance. Done means the developer has committed and pushed, which the agent confirms read-only. The kit's process docs, skills, agents and templates, and the kanban plugin's stages, board and tests follow the new flow, and tickets already in Demo or E2E keep working.
